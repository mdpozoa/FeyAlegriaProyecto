# SafeCampus Monitor

## Descripción
SafeCampus Monitor es una aplicación web desarrollada para el proyecto integrador (enfocado en la comunidad de Fe y Alegría). Su objetivo principal es permitir a los estudiantes reportar incidentes de seguridad y a las autoridades monitorear zonas críticas mediante un dashboard interactivo geolocalizado.

## Stack Tecnológico
- **Frontend Core:** Vue.js 3 (Composition API)
- **Tooling:** Vite
- **Manejo de Estado:** Pinia
- **Enrutamiento:** Vue Router
- **Mapas:** Leaflet
- **Estilos:** Vanilla CSS (Diseño moderno, sin frameworks externos pesados)
- **Despliegue:** Vercel

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/mdpozoa/FeyAlegriaProyecto.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```
